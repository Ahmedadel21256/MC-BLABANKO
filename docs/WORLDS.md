# SHABAB SMP — Worlds and generated maps

## What is included in the repository
The `ShababCore` plugin contains **procedural map generators**, committed as Java source. These do **not** contain Minecraft `region/*.mca` files or zipped prebuilt worlds: the map blocks are placed when the corresponding Paper backend is started with the updated compiled plugin.

| Backend | Fresh world behavior | Location |
|---|---|---|
| lobby | A circular spawn platform, decorative colored arches, selector NPC, shop NPC | 0, 190, 0 |
| survival | Minecraft Paper generates a normal new Survival world | Normal spawn |
| bedwars | Four-team **practice** islands, team-colored markers, decorative bed markers | Y=225, centers about 39 blocks from 0 |
| skywars | Eight **practice** islands with starting chests and center island | Y=225, centers about 32 blocks from 0 |

The lobby is generated by `HubBuilder`. The minigame island layouts are generated by `ArenaBuilder`. They run only for matching backend values of `server-name`, skip if a saved marker exists, and refuse construction if blocks exist in the intended space. No existing worlds are deleted by these generators.

**These are preliminary layouts, not complete BedWars or SkyWars games.** Beds, match rounds, shop generators, team assignments, round-based arena reset, PvP handling, and lobby queues need compatible plugins and configuration. Likewise, the decorative Lobby arches are not portals; players use the selector NPC or `/games`.

## Why the worlds are not available to join yet
Only source files and tests can be changed using GitHub's repository connection. The actual Codespaces runtime holds Minecraft region files under `shabab-network/*/world`, and those files are not automatically uploaded to or modified by GitHub commits. Codespaces must sync the new code, build `ShababCore`, install the jar on backends, then start the Paper servers so world generation occurs.

## Protecting the existing worlds
The generated worlds use **new server directories** beneath `shabab-network`; no code deletes the old `minecraft-server` folder. World data, player data and plugins' secrets are deliberately excluded from Git commits. Always stop/save worlds before backing up or changing servers.

## Access and OP
The network's offline-mode Velocity entry is loopback only. It cannot be accessed from a Windows TLauncher client directly. The generated local operator entry for `I_luca1` is not a safe public authentication method; keep the unverified-name network private.
